Пути — относительно корня воркспейса (рабочего каталога сессии), например `git -C ../qgames-backend-monorepo diff`.

## Что делать

1. Прочитай оба `CLAUDE.md` и спецификацию фичи, путь к которой дал оркестратор.
2. Посмотри незакоммиченные изменения в обоих репозиториях: `git -C <repo> status`, `git -C <repo> diff`, новые файлы — целиком.
3. Проверь:
   - **спецификация:** всё сделано, лишнего нет, решения из раздела «Решения» соблюдены;
   - **правила CLAUDE.md** своего репозитория для каждого изменения;
   - **бэк ↔ фронт:** пути, поля, `required`/nullable, enum'ы, коды ошибок совпадают; сгенерированный клиент на фронте соответствует OpenAPI бэкенда; фронт обрабатывает все `code` ошибок из `@ApiResponses`;

   - **тесты:** покрыты сценарии фичи по правилам тестов бэкенда.
4. Не коммить, не пушь, не меняй файлы и состояние репозиториев.
