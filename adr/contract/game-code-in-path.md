# Идентификатор игры и настройки в контракте

Область: backend, frontend · Диаграммы: [c4/3-backend-game](../c4/3-backend-game.md), [c4/3-frontend-portal](../c4/3-frontend-portal.md) · Код: `GameCode`, `GameCodes`, `GameRoomApi`, `GameSettingsDto`

## Контекст

Ручки создания комнаты, настроек и хода зависят от игры, а схемы настроек и ходов у игр разные. Фронту нужны типизированные настройки и их границы для формы.

## Решение

- **Код игры — единственный идентификатор игры** во всём стеке (`nothing`, `checkers`, `carcassonne`): в путях API, в URL портала, в дискриминаторе, в имени пакета игры. Enum `GameCode` сериализуется строчным кодом.
- **Код игры — в пути:** `/api/games/{gameCode}/rooms/...` (создание, настройки, ход). В теле код не передаётся. Неизвестный код — 404 `GAME_NOT_FOUND`, несовпадение с игрой комнаты — 409 `GAME_TYPE_MISMATCH`.
- Ход — конверт `{type, data}`, схемы `data` игр публикуются в components.
- Настройки игры — **полиморфные simple и advanced** (`oneOf` по `gameCode` в корне каждой группы, [room-settings](../game/room-settings.md)). Границы и значения по умолчанию отдаёт `GET /api/games/{gameCode}` (`rules`).

## Рассмотренные варианты

| Вариант | Почему нет |
|---|---|
| `gameType` наряду с кодом игры (`GameType.NOTHING` + `nothing`) | Два идентификатора одной сущности, их приходится сопоставлять в каждом маппере и на фронте |
| `gameType` в теле запроса (`POST /api/rooms {gameType}`) | Тип игры в каждой ручке передаётся по-разному |
| Ход без кода игры в пути (`/api/rooms/{id}/session/moves`, тело `{move}`) | Из запроса не видно, чей это ход; некуда повесить схему хода игры |
| Ключ настроек по имени игры (`nothing: {...}`) | Дублирует дискриминатор |
| Плоские nullable-поля настроек / нетипизированный `settings` | Поля копятся с каждой игрой / нет типов на фронте |
| Только `@Min/@Max` в DTO без ручки параметров игры | Границы одинаковы для всех игр, режимы фронт знал бы сам |

## Последствия

- Новая игра добавляет варианты в union simple, advanced и границ настроек и значение в `allowableValues` пути (чек-лист — `backend/games/CLAUDE.md`).
- Форма настроек на фронте ничего не хардкодит.
