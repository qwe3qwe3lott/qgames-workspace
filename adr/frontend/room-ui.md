# Интерфейс комнаты

Область: frontend · Диаграммы: [c4/3-frontend-portal](../c4/3-frontend-portal.md) · Код: `features/room-membership`, `pages/room`, `shared/ui` (`WithHint`)

## Контекст

На странице комнаты много действий, доступных не всегда (смена роли, пауза, передача владения), а связь может рваться. Пользователь должен понимать, почему действие недоступно, и не делать лишних кликов.

## Решение

- Вход и выход автоматические: присутствие = открытый поток ([room-presence](../game/room-presence.md)). При обрыве видна плашка «Нет связи… переподключаемся», без кнопки.
- Роль меняется кнопкой «Перейти» в заголовке списка, где пользователя нет. Оба списка («Игроки», «Наблюдатели») видны всегда.
- Заблокированные действия показывают причину через **Tooltip** (`WithHint`).
- Кнопки паузы показываются **только при активном таймере**. «Отменить» у владельца есть всегда.
- Ошибки действий вне форм показываются снекбаром.

## Рассмотренные варианты

| Вариант | Почему нет |
|---|---|
| Кнопки «Стать игроком» / «Стать наблюдателем» в сайдбаре | Решение пользователя: переключение — в самих списках |
| Показ пауз у партии без таймера (кнопка с ошибкой или заблокированная) | Заведомо бесполезная кнопка |
| Подсказки через атрибут `title` | Появляются с задержкой, выглядят системно |

## Последствия

- Курсоры (`pointer`/`not-allowed`) и запрет `disabled:pointer-events-none` закреплены в правилах (`frontend/CLAUDE.md` §4).
