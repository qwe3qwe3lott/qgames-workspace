# UI-кит и стили

Область: frontend · Диаграммы: [c4/3-frontend](../c4/3-frontend.md) · Код: `frontend/packages/ui`

## Контекст

У двух приложений должен быть единый дизайн без копирования компонентов. Стили должны быть предсказуемыми, без смеси подходов.

## Решение

- **Tailwind 4 + shadcn/ui** в общем пакете `@qgames/ui`: компоненты, тема (`globals.css`), общие компоненты разметки (`PageLayout`). Новые компоненты shadcn добавляются туда.
- Только utility-классы и компоненты кита: без CSS-модулей, CSS-in-JS и inline `style` (кроме динамических значений).
- **Темы:** `ThemeProvider` (next-themes). Сейчас тема только light (`forcedTheme`), но механизм тем (`dark:`, `.dark`) не выпиливается.
- Снекбар — Sonner. Подсказки — Tooltip кита.

## Рассмотренные варианты

| Вариант | Почему нет |
|---|---|
| shadcn/ui отдельно в каждом приложении | Дублирование кода, дизайн расходится |

## Последствия

- Изменение темы меняет оба приложения сразу.
