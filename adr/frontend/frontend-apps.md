# Приложения фронта и сборка

Область: frontend · Диаграммы: [c4/3-frontend](../c4/3-frontend.md), [c4/3-frontend-portal](../c4/3-frontend-portal.md) · Код: `frontend/apps/*`, `rsbuild.config.ts`

## Контекст

Порталу и админке не нужен SEO на этапе MVP, а нужны быстрые сборка и разработка и чанки по маршрутам. Статика раздаётся тем же nginx, что проксирует API.

## Решение

- Два **CSR SPA** — `apps/portal` (:3000) и `apps/admin` (:3001) — на **Rsbuild (Rspack)** и **TanStack Router** (file-based, `autoCodeSplitting`, search params через Zod).
- Node.js 24 LTS. Приложение зависит только от `packages/*`, никогда от другого приложения.
- В Docker собирается прод-сборка (nginx), для разработки используется `pnpm dev` локально.
- Переменные `PUBLIC_*` читаются в одном месте и валидируются Zod. Секретов во фронте нет, адреса API в env нет (same-origin).

## Рассмотренные варианты

| Вариант | Почему нет |
|---|---|
| Чистый Rspack (`@rspack/cli`) | Большой ручной конфиг (loaders, HMR, PostCSS, HTML) |
| Node.js 22 | Maintenance LTS, поддержка заканчивается в апреле 2027 |
| Dev-режим (`pnpm dev`) в контейнере | bind-mount на Windows медленный, вотчеры капризны |

## Последствия

- Нет SSR: страницы не индексируются поисковиками. Пересмотреть, если понадобится SEO.
- Тесты фронта не выбраны — решить при появлении первой фичи (BACKLOG «Фронт: тестов нет»).
