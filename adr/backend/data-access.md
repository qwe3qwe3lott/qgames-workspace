# Хранилище и доступ к данным

Область: backend · Диаграммы: [erd/user-auth](../erd/user-auth.md), [erd/admin-auth](../erd/admin-auth.md), [erd/game](../erd/game.md) · Код: `backend/<m>/<m>/.../table`, `repository`

## Контекст

Данных немного, памяти мало (VPS 1 ГБ), конкурентные мутации комнат требуют надёжных блокировок, а для рассылки событий нужен механизм уведомлений. Сырой SQL в коде хочется исключить.

## Решение

- **PostgreSQL 18**, одна БД `qgames` и одна роль на приложение. Их создаёт сам образ из `POSTGRES_USER`/`POSTGRES_DB`. Модуль пишет только в свои таблицы.
- **Exposed DSL** (без DAO) в транзакциях Spring (`SpringTransactionManager`). Сырого SQL нет. Единственное исключение — `pg_notify`/`LISTEN`, для них у Exposed нет DSL. Поэтому нет `RETURNING`, CHECK и частичных индексов: значения проверяет код через enum.
- **Типы:** id — UUID v7 от приложения (`uuid`); время — `timestamptz`, `Instant` из бина `Clock`; JSON — `json` (текст как записан).
- Пул Hikari — 5 соединений плюс одно соединение LISTEN вне пула.
- Имена таблиц — в единственном числе, snake_case, уникальны в приложении ([migrations](migrations.md)).

## Рассмотренные варианты

| Вариант | Почему нет |
|---|---|
| JPA/Hibernate | Больше памяти и магии сессий и ленивых связей |
| Spring Data JDBC (`CrudRepository`, `@Query`, `JdbcClient`) | `@Query` и `JdbcClient` — сырой SQL, непереносимый между БД |
| Встраиваемая SQLite | Один писатель на всю БД; конкурентность через sqlite-jdbc требовала обхода драйвера и тонких настроек транзакций |
| `bigint identity` для id | Предсказуемые id, неизвестны до вставки |
| Имена таблиц во множественном числе | Решили единообразно в единственном |
| Создание ролей и БД init-скриптом (`postgres-init`) | Роль одна, её создаёт сам образ |
| `jsonb` для JSON-колонок | Поля JSON не запрашиваем, а `jsonb` переставляет ключи (решение пользователя) |
| `timestamp` без пояса + UTC в JVM | Корректность держалась бы на поясе JVM |

## Последствия

- Всё проверяется типами Kotlin, схема переносима (абстрактный Liquibase).
- Ограничения уровня данных (CHECK) заменяет код. Гонки на уникальных индексах дают 409 ([backend-layers](backend-layers.md)).
